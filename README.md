# A/B-тест алгоритма ранжирования ленты

## О проекте
Развлекательное приложение с короткими видео. Команда ML предложила новый алгоритм ранжирования.

**Гипотеза:** улучшенная персонализация увеличит долю успешных сессий (4+ страницы).

**Задача:** спланировать эксперимент, проверить данные и оценить влияние нового алгоритма на целевую метрику.

## Стек
- Python, Pandas, Matplotlib
- statsmodels — Z-тест для пропорций
- Расчёт размера выборки через NormalIndPower (мощность 80%, MDE 3%, a = 0.05)

## Этапы и результаты

**1. Планирование**
- Базовый уровень метрики ≈ 31%.
- Нужно по 41 040 пользователей в каждую группу.
- Длительность теста — 9 дней (по DAU).

**2. Проверка данных**
- Разница размеров групп < 1%.
- Пересечений пользователей нет.
- Распределение по ОС и регионам одинаковое.

**3. Результаты**
- Группа A: 31.57% успешных сессий
- Группа B: 31.47% успешных сессий
- p-value = 0.578

## Рекомендация
Разница статистически незначима, новый алгоритм не повышает вовлечённость. Отказываемся от раскатки на всех пользователей. Алгоритм нужно доработать или оставить старый.

## Структура репозитория
- `analysis.ipynb` — планирование, проверка данных и A/B-тест

## Как запустить
1. Установите: `pandas`, `matplotlib`, `statsmodels`
2. Откройте `analysis.ipynb`
